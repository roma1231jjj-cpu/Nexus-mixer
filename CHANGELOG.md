# Changelog

## 0.4.2 — 2026-11-24

### Исправлено
- Секвенсор: шаги обновляются без мутации состояния, первый шаг срабатывает сразу, таймер не сбивается при перерисовках, смена BPM применяется со следующего шага, при остановке глушатся все сэмплы.
- Секвенсор: подписи переведены на русский и английский (добавлен ключ BPM).
- Сэмплер: смена сэмпла больше не закрывает общий AudioContext; очистка только при закрытии панели.
- Сэмплер: некорректное смещение начала сэмпла ограничивается длиной буфера вместо исключения Web Audio.
- Горячие клавиши: сочетания с цифрами определяются по коду клавиши, не зависят от раскладки; Ctrl/Alt не запускают буквенные действия.
- Макросы: удержание не срабатывает повторно и корректно сбрасывается на pointerup/cancel; применение пресета учитывает выбранную цель.
- Обновления: повторная загрузка начинается с нуля, «готово» ставится по завершении.
- Сцены: сохраняются cue, phantom и aiPresetId; старые файлы читаются.
- Виртуальные кабели: миграция выполняется один раз, даже если найден не весь набор.
- Шины A2/A3: не получают автоматическое назначение, устаревшее устройство очищается.
- Голосовые команды: «clear voice» больше не воспринимается как сброс эффектов; отрицание проверяется по трём предыдущим словам.
- Фейдеры: колесо мыши работает и реально блокирует прокрутку страницы.
- Выделение диапазона по Shift больше не захватывает скрытые каналы.
- Undo/redo: последняя правка не теряется перед отменой.
- Rust-движок: AI-аудио читается после заголовка, стерео сводится в моно, UI и аудиопоток используют один AI-клиент, имя WAV уникально до миллисекунд, в AI идут только слышимые каналы, fallback системного буфера сообщается наружу, текст ошибки запуска совпадает с таймаутом 45 с.

### Оптимизация
- EQ-мини-кривая не пересчитывается без изменения параметров (React.memo).
- Секвенсор не перезапускает цикл при обновлении родительских коллбэков.

## 0.4.0 — 2026-11-22

### Добавлено

- **Три темы оформления** с общим дизайн-языком:
  - **Nexus-Studio** — текущая матовая приборная панель;
  - **Nexus-Noir** — чёрное стекло, фиолетовое свечение, размытие;
  - **Nexus-Frost** — белое стекло, синий акцент, размытие.
- Переключение темы в тулбаре по кругу и в **Настройки → Интерфейс**.
- `?theme=studio|dark|light` для детерминированных скриншотов и презентаций.
- Три формата поставки: **NSIS-установщик**, **одиночный portable .exe**,
  **portable .zip**. Артефакты раскладываются в `release/vX.Y.Z/`.
- Подпись **Nexus × АутSquad** в титлбаре.
- Портативный `.exe` умеет переименовывать кабели без внешней папки resources.

### Изменено

- Старые сохранения с темой `dark` мигрируют в `Nexus-Studio`, чтобы обновление
  не меняло привычный вид консоли неожиданно.
- Версия 0.4.0 во всех манифестах, установщике и статус-баре.

### Проверено

- 54 Rust-теста, TypeScript typecheck, production Vite build.
- Переключение Studio → Noir → Frost → Studio без перезапуска.
- Скриншоты всех трёх тем сняты с версии 0.4.0.

## 0.3.0 — 2026-11-22

### Добавлено

- **Автообновление** через GitHub Releases и Tauri Updater:
  - проверка `latest.json` при запуске;
  - фоновая загрузка подписанного NSIS-пакета;
  - кнопка «Установить и перезапустить»;
  - ручная проверка в **Настройки → Обновления**.
- **Локальные голосовые пресеты** без Python и скачивания моделей:
  Монстр, Демон, Великан, Ребёнок, Женский, Пришелец, Робот, Шёпот.
- Выбор источника голоса: микрофон или другой вход.
- Полноценный GitHub-репозиторий: README, CI и Release workflow.

### Исправлено

- ИИ-голос был привязан к виртуальному входу VAIO вместо микрофона.
- Фейдер VCA-группы сжимался до ~2 см.
- Настройки могли открываться за скримом рэка, матрица перекрывала рэк.
- Шум кулеров оставался слышимым из-за слишком мягкого диапазона гейта.
