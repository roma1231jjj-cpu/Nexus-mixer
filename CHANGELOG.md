# Changelog

## 0.5.0 — 2026-11-25

### Исправлено: Soundpad (критичное)
- **Сэмплы больше не идут мимо микшера.** Раньше выбор канала/шины создавал только Web Audio gain и звук всегда шёл в системное устройство WebView. Теперь в Rust-движке есть банк сэмплов: PCM загружается в движок, голос суммируется в вход выбранного канала (до EQ/компрессора/VCA), в шину (до её обработки) или в мастер-сумму (до master EQ/гейна), и только потом попадает в реальные выходы.
- Выбор канала/шины действительно применяет обработку этого канала, а не только громкость.
- **Файлы сэмплов сохраняются.** Раньше в localStorage жили только метаданные: после смены вкладки или перезапуска пэды были «мёртвыми». Теперь файл лежит в IndexedDB, при старте декодируется и снова загружается в движок; если файла нет — пэд честно помечается «нет файла» и предлагает подставить его заново (проверено на пустом хранилище).
- Soundpad: громкость, панорама, pitch, loop и mute/громкость целевого канала применяются к уже играющему звуку, а не только к следующему запуску; первый запуск учитывает выставленную громкость.
- Индикатор уровня пэда — реальный пик из движка (или анализатора превью), а не `Math.random()`.
- Если движок остановлен, панель честно пишет, что звук идёт только в системный выход мимо каналов, и показывает, когда маршрутизация реально работает.
- **Загрузка сэмпла в движок быстрее.** PCM идёт в Rust не JSON-массивом чисел (~9 МБ на 4 минуты стерео), а base64 от little-endian f32 (~2.5 МБ): Rust декодирует буфер за миллисекунды, IPC не давится текстом.
- Плашки панели PADS больше не наезжают на кнопки: у строки «маршрутизация/браузер», кнопки загрузки, громкости и «Стоп» свои места, текст плашки — 10 px вместо унаследованных 16.
- Секвенсор: шаг всегда **перезапускает** сэмпл (раньше повторный шаг работал как play/stop), шаги планируются по `performance.now()` с упреждением 25 мс, а движку передаётся остаточная задержка — ритм не уплывает под нагрузкой. Паттерн и BPM сохраняются при закрытии панели и перезапуске.

### Исправлено: запись
- Изменение настроек записи больше не перезапускает файл: шины/глубина/папка/разбиение применяются к следующей сессии, в UI — плашка «применится после остановки».
- Остановка записи дописывает хвост очереди в файл (раньше последние кадры терялись), затем корректно финализирует WAV.
- Автоматическое разбиение по пределу RIFF (~4 ГБ) даже при выключенном разбиении по времени — без разрывов и потерь.
- Пустая маска шин больше не подменяется на A1: старт падает с понятным текстом, кнопка записи блокируется.
- Ошибка записи не затирается изменением параметров и живёт до успешного старта.
- Кнопка записи больше не рапортует «начато» до подтверждения от writer; таймер идёт по данным backend; кнопка папки открывает настоящий диалог выбора.

### Исправлено: движок и управление
- Гонка старт/стоп: остановка во время открытия устройств больше не даёт движку включиться задним числом.
- Статус показывает фактический размер буфера (измеренный по колбэкам), если WASAPI отверг запрошенный, и задержка считается по нему.
- `safetyMs` теперь реально влияет на путь аудио: увеличивает кольца захвата и добавляет измеряемый прогрев, а не только число в статусе.
- PANIC при повторном нажатии восстанавливает прежние mute, а не разглушает всё подряд.
- Momentary-макросы: нажатие применяет действие, отпускание возвращает состояние; горячая клавиша работает как удержание и не повторяется автоповтором.
- Одинаковые имена устройств больше не сливаются в один пункт: id получает устойчивый суффикс `#2`/`#3`, а меню показывает «Microphone #2».
- Пропавшие устройства больше не подменяются другими: назначение сохраняется до возвращения устройства; намеренно пустой канал не заполняется сам.
- Undo/redo теперь покрывает фейдеры, pan, mute/solo, маршрутизацию, имена, FX, шины, master EQ/гейн и VCA — раньше только FX.
- Сцены сохраняют имена каналов, назначения устройств, настройки движка и полные настройки AI.
- Ошибки сохранения сцен и сэмплов показываются, а не проглатываются; ошибки движка больше не перетираются фоновым опросом; перезапуск движка не игнорирует неудачную остановку.

### Изменено: движок, устройства, форматы
- Вход с частотой, отличной от мастер-клокa, больше не выбрасывается: конфиг берётся лучший из поддерживаемых, а в capture-колбэке работает линейный ресемплер без аллокаций; в статусе честное предупреждение о ресемплинге.
- Поддержаны I16/U16/I32/F64 (раньше только F32): стримы строятся как raw, конвертация идёт в предвыделенный scratch-буфер кусками по границам кадров; F32 больше не обязателен ни для входа, ни для выхода, ни для мастера.
- Дрейф часов между устройствами компенсируется по заполнению кольца (±300 ppm, шаг ≤ 1 ppm за колбэк), поэтому длинная сессия не упирается в XRUN.
- Убран скрытый дефект: fallback «WASAPI отверг фиксированный буфер» вызывал фабрику колбэка дважды и мог паниковать в аудио-потоке; теперь размер проверяется пробным тихим стримом, а рендерер строится один раз. Пад-банк получает фактическую частоту мастер-клока.
- Устройства с одинаковыми именами разводятся по id (`in:Mic#2`) при сохранении старого формата для первого вхождения; дефолтным считается только первый эндпоинт.

## 0.4.3 — 2026-11-25

### Оптимизация
- Панели, которые открываются действием пользователя, вынесены в отдельные чанки через `React.lazy` + `Suspense`: док река (`RackDock`), вкладки AI (`AiPanel` вместе с `AiConfig`), PADS (`SoundPlayer` + `Sequencer`), REC (`RecordPanel`), настройки (`SettingsDrawer`), руководство (`GuideSheet`), горячие клавиши (`ShortcutsSheet`), матрица маршрутизации (`RoutingMatrix`), настройка кабелей (`CableSetupDialog`).
- Пока чанк грузится, показывается скелет `PanelSkeleton` в цветах темы: той же высоты для дока, без второго затемнения и без повторной анимации слайда для drawer/dialog/overlay — открытие не мигает.
- `vite.config.ts`: `manualChunks` разделяет `react`/`react-dom`, `lucide-react` и прочих вендоров (`zustand`, `clsx`, плагин обновлений).

### Размеры бандла (production, до → после)
- Основной чанк `index.js`: **521.98 КБ (gzip 154.67) → 165.85 КБ (gzip 51.60)** — меньше 500 КБ, предупреждение Rollup ушло.
- Разделение вендоров: `react.js` 214.63 КБ (gzip 66.62), `lucide.js` 36.47 КБ (gzip 9.28), `vendor.js` 4.52 КБ (gzip 1.86), `window.js` 15.49 КБ (gzip 3.92).
- Первый экран (index + react + lucide + vendor + window): **537.44 КБ → 436.96 КБ**, gzip **158.57 → 133.28 КБ** (−16 %).
- Ленивые чанки грузятся по требованию: `RackDock` 42.32 КБ (gzip 12.68), `AiPanel` 19.95 (6.02), `SoundPlayer` 14.79 (5.16), `SettingsDrawer` 12.06 (3.22), `GuideSheet` 5.62 (1.69), `RecordPanel` 3.86 (1.42), `CableSetupDialog` 2.85 (1.17), `RoutingMatrix` 2.84 (1.34), `ShortcutsSheet` 1.62 (0.79).
- Суммарно по всем JS-чанкам gzip 163.11 КБ против 158.57 КБ до разделения (+3 %) — плата за отдельные чанки; выигрыш на старте 25.3 КБ gzip. CSS не менялся: 267.89 КБ (gzip 45.14).

### Изменено
- Версия 0.4.3 в `package.json`, `src-tauri/Cargo.toml`, `src-tauri/tauri.conf.json`; версия в статус-баре и в настройках больше не отстаёт от манифестов.

## 0.4.2 — 2026-11-24

### Исправлено
- Секвенсор: шаги обновляются без мутации состояния, первый шаг срабатывает сразу, таймер не сбивается при перерисовках, смена BPM применяется со следующего шага, при остановке глушатся все сэмплы.
- Секвенсор: подписи переведены на русский и английский (добавлен ключ BPM).
- Сэмплер: смена сэмпла больше не закрывает общий AudioContext; очистка только при закрытии панели.
- Сэмплер: некорректное смещение начала сэмпла ограничивается длиной буфера вместо исключения Web Audio.
- Горячие клавиши: сочетания с цифрами определяются по коду клавиши, не зависят от раскладки; Ctrl/Alt не запускают буквенные действия.
- Макросы: удержание не срабатывает повторно и корректно сбрасывается на pointerup/cancel; применение пресета учитывает выбранную цель.
- Обновления: повторная загрузка начинается с нуля, «готово» ставится по завершении.
- Сцены: сохраняются cue, phantom и aiPresetId; старые файлы читаются.
- Виртуальные кабели: миграция выполняется один раз, даже если найден не весь набор.
- Шины A2/A3: не получают автоматическое назначение, устаревшее устройство очищается.
- Голосовые команды: «clear voice» больше не воспринимается как сброс эффектов; отрицание проверяется по трём предыдущим словам.
- Фейдеры: колесо мыши работает и реально блокирует прокрутку страницы.
- Выделение диапазона по Shift больше не захватывает скрытые каналы.
- Undo/redo: последняя правка не теряется перед отменой.
- Rust-движок: AI-аудио читается после заголовка, стерео сводится в моно, UI и аудиопоток используют один AI-клиент, имя WAV уникально до миллисекунд, в AI идут только слышимые каналы, fallback системного буфера сообщается наружу, текст ошибки запуска совпадает с таймаутом 45 с.

### Оптимизация
- EQ-мини-кривая не пересчитывается без изменения параметров (React.memo).
- Секвенсор не перезапускает цикл при обновлении родительских коллбэков.
