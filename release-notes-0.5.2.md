# Nexus Mixer 0.5.2

- **Ошибки записи WAV больше не проглатываются.** `finalize()` возвращает ошибку flush/header/seek/sync; она попадает в отчёт записи.
- **Гонка start/stop движка закрыта.** Проверка поколения и установка runtime идут под одним lock — остановка во время открытия WASAPI не оставляет работающий «мёртвый» движок.
- **B1/B2 не перезаписываются.** Автопривязка к кабелю только при первой миграции; пустое назначение и временно пропавшее устройство сохраняются.
- **PAD не зависает в `playing`.** Тихий/короткий one-shot очищается по длительности сэмпла, даже если уровень не поднялся.
- **Секвенсор сообщает об ошибке сохранения** паттерна.
- **Задержка подписана как оценка**, а не точное измерение.

Тесты: `cargo test --lib` — 101 passed, 4 ignored. `npm run build` — ok.
