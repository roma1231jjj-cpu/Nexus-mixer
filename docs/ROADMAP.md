## Этап 2 — Аудиодвижок ✅ shared

### 2.1 Backend

- [x] Ring buffer без аллокаций (SPSC, power-of-two).
- [x] WASAPI shared через `cpal`; endpoint id из friendly name.
- [x] Clock master: один output stream задаёт частоту, остальные шины идут через SPSC.
- [x] Xrun-детект (underrun/overrun) и CPU-load в статус-баре.
- [x] Hot-plug: список endpoint'ов обновляется раз в 4 с; при потере устройства
  граф пересобирается с новыми fallback-устройствами.
- [x] Watchdog: если счётчик кадров master-callback замирает на 3 секунды,
  движок автоматически перезапускается (с защитой от циклов).
- [ ] WASAPI exclusive / WDM-KS как опция.
- [ ] ASIO — после стабилизации WASAPI.
- [ ] `IMMNotificationClient` вместо опроса (мгновенная реакция на hot-plug).
- [ ] Drift compensation между независимыми устройствами.

### 2.2 Граф

- [x] `ChannelStrip`: gain → phase → gate → comp → EQ → de-ess → sat → tilt.
- [x] `RoutingMatrix`: 25 send'ов, уровни в dB.
- [x] `Bus`: EQ → delay → width → gain → limiter.
- [x] `GraphParams` — fixed-size `Copy`, очередь без аллокаций в callback.
- [x] Метры peak на канал и шину, публикация atomics → UI 20 Гц.

### 2.3 Интеграция с UI

- [x] `useEngineBridge` шлёт snapshot'ы с debounce 60 мс.
- [x] `MeterRefs` переключаются на реальные пики движка.
- [x] Статус-бар показывает CPU, xrun, реальную задержку, потоки и предупреждения.
- [x] Кнопка Start/Stop реально управляет движком.
- [x] Понятные ошибки старта, авто-выбор default-выхода, fallback браузерной симуляции.
- [x] Авто-рестарт после потери устройства или остановки аудиопотока.

**Критерий готовности:** тон 1 кГц проходит `hw1 → A1` без щелчков, матрица и
mute работают, xrun = 0 за 10 минут. Shared-тракт проверен smoke-тестом с
реальными default-входом/выходом; длительный soak-тест — следующий шаг.

## Риски

| Риск | Влияние | Смягчение |
| --- | --- | --- |
| Сложность WASAPI exclusive | задержка, совместимость | shared по умолчанию, exclusive опцией |
| Подпись драйвера (EV + attestation) | деньги и время | начать с test mode, параллельно оформлять сертификат |
| RVC-качество на CPU | RTF < 1 | квантизация ONNX, DirectML, GPU-требование для AI-режима |
| Дрейф часов между устройствами | щелчки, xrun | clock master + drift compensation |
| Потеря endpoint'а (USB/Bluetooth) | обрыв звука | hot-plug watcher + безопасный авто-рестарт графа |
| Антивирусные ложные срабатывания на драйвер | установка | подпись, WHQL, прозрачная документация |
