# Security

Не публикуйте приватные ключи, токены и личные записи в issues.

Для сообщений об уязвимостях используйте приватный security advisory в GitHub
или напишите владельцу репозитория. Пожалуйста, не открывайте публичный issue
до исправления.

## Updater signing

Публичный ключ Tauri Updater находится в `src-tauri/tauri.conf.json`.
Приватный ключ хранится только локально и в GitHub Actions Secrets.
Если ключ скомпрометирован — выпустите новый ключ и новый релиз.
